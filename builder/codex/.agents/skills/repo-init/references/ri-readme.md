# README.md 模板

## 模板

```markdown
# <项目名>

> <一句话定位：这是什么，解决什么问题>

## 快速上手

```bash
# 安装
<安装命令>

# 配置
cp .env.example .env   # 填入必要配置

# 启动
<启动命令>
```

## 功能

- <核心功能 1>
- <核心功能 2>
- <核心功能 3>

## 文档

- [架构 & 开发指南](CLAUDE.md)
- [路线图](PLAN.md)

## 依赖要求

- <运行时 / 语言版本>
- <关键依赖>
```

## 原则

- README 是**用户视角**（CLAUDE.md 是开发者视角）
- 快速上手必须可执行，新人 5 分钟内能跑起来
- 不要把所有文档堆进 README，用链接指向 CLAUDE.md / PLAN.md
