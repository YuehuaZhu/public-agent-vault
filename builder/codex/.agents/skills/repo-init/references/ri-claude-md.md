## 填写要点

| 章节 | 必填 | 说明 |
|------|------|------|
| 标题 + 一句话描述 | ✅ | 项目定位，越具体越好 |
| 快速上手 | ✅ | 新人 5 分钟跑通的最小步骤 |
| 架构图 | ✅ | ASCII 即可，重要的是把主要模块关系画清楚 |
| 目录结构 | ✅ | 只列一级/二级，加简短注释 |
| 开发流程 | ✅ | 具体命令，不要写废话 |
| 常见问题 | 可选 | 把排障过程中发现的坑记下来 |

## 关键原则

- **不写废话**：每行都应该是新人看不到就会踩坑的信息
- **命令可直接复制执行**：不要写 `<your-command>`，要写实际命令
- **架构图优先**：让人先看懂整体再看细节
